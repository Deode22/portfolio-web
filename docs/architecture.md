# Architecture

The portfolio is one `/app/page.tsx` route, six server-rendered sections,
and one client-only map sandbox. State is local; nothing is fetched at
request time other than the GeoJSON layers.

## Layout

```
src/
├── app/
│   ├── layout.tsx       font wiring, body, skip-link, metadata
│   └── page.tsx         composes the six sections in order
├── components/
│   ├── site/             site-header.tsx (sticky mono nav)
│   ├── sections/        one file per top-level section + small cards
│   │                     hero-section, hero-stat, map-sandbox-section,
│   │                     projects-section, project-card, pipeline-section,
│   │                     stack-section, contact-section
│   ├── map/             client-only map sandbox
│   │                    map-sandbox (orchestrator), map-canvas (MapLibre),
│   │                    map-layer-toggle (ToggleGroup), map-feature-panel,
│   │                    feature-table (no-WebGL fallback)
│   └── ui/              shadcn primitives + AssetImage
├── data/                typed copy and config (projects, skills, stats…)
└── lib/                 utils, webgl feature detection, maplibre-style

public/
├── documents/            CV placeholder (TODO)
├── images/               avatar (moved) + og-image (TODO)
├── projects/             4 project previews (all TODO)
├── geojson/              4 mock feature layers (TODO replace)
└── maplibre/             mirrored MapLibre ESM worker + shared chunk

scripts/sync-assets.mjs   asset inventory + MapLibre vendor mirror
docs/                     long-form docs (this folder)
```

## Data flow

`src/data/*.ts` files are the single source of truth for copy, metrics, and
configuration. None of the JSX hard-codes strings — section files only read
from there. This makes it cheap to:

- Copy-edit copy without grepping JSX.
- Re-shape the bento by changing `span` in `projects.ts`.
- Swap GeoJSON by editing `map-layers.ts` (no canvas changes needed).

The asset manifest (`src/data/assets.generated.ts`) is regenerated by
`scripts/sync-assets.mjs` on every `predev` / `prebuild`. Components read
`assets[path]` and decide at render time whether to render an `<Image />` or
the hairline-bordered `AssetPlaceholder`.

## Server vs client

| File                                  | Why client                                       |
| ------------------------------------- | ------------------------------------------------ |
| `src/app/layout.tsx`                  | Server — fonts, metadata                         |
| `src/app/page.tsx`                    | Server — composes sections                       |
| `sections/hero-section.tsx`           | Server — section chrome                          |
| `sections/hero-stat.tsx`              | **Client** — `useInView` + `useSpring`          |
| `sections/map-sandbox-section.tsx`    | Server shell                                     |
| `map/map-sandbox.tsx`                 | **Client** — owns dynamic canvas + UI state      |
| `map/map-canvas.tsx`                  | **Client** — MapLibre touches `window`          |
| `sections/projects-section.tsx`       | Server — pure render                            |
| `sections/pipeline-section.tsx`       | **Client** — `motion.path` + `whileInView`      |
| `sections/stack-section.tsx`          | Server                                           |
| `sections/contact-section.tsx`        | Server                                           |
| `site/site-header.tsx`                | Server                                           |

The map is loaded after hydration via `useEffect(() => import("@/components/map/map-canvas"))`,
not via `next/dynamic({ ssr: false })`. The latter produces hydration
mismatches because the SSR pass renders the loading state and the client
moves past it.

## Map sandbox detail

```
map-sandbox (orchestrator, owns: activeLayerId, selected feature, needsFallback)
├── MapLayerToggle (ToggleGroup, 4 layers, single-select)
├── MapCanvas              (mount-gated useEffect import of MapLibre)
├── MapFeaturePanel        (right-side rail, hidden when no feature selected)
├── FeatureTable           (always visible: plain HTML tables of every layer)
└── Map canvas status: live / degraded / fallback (webgl check)
```

`map-canvas.tsx` is the single owner of the MapLibre `Map` instance; it
mounts the map, swaps the source on `activeLayerId` change, and tears it
down on unmount. Worker URL is set at module scope (so it runs before any
`new MLMap(...)`) to `/maplibre/maplibre-gl-worker.mjs`, mirrored from
`node_modules/maplibre-gl/dist/` by `scripts/sync-assets.mjs`.

## Build / dev sanity checks

Run in order:

```bash
npx tsc --noEmit           # type safety
npx eslint "src/**/*.{ts,tsx}"  # lint (zero errors required)
npm run build              # production build
npm run dev                # smoke test in browser; check .next/dev.log
```

The dev server forwards browser console errors to the terminal — if a
hydration mismatch appears, it shows up there with line numbers.
